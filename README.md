# Temporal Industries

A NeoForge mod for Minecraft 1.21.1 focused on temporal mechanics and industrial automation.

## Requirements

- Minecraft 1.21.1
- [NeoForge](https://neoforged.net/) 21.1.235+

## Building

```
./gradlew build
```

The built jar will be output to `build/libs/`.
```
